# 后台模板视觉与操作自审

当前追加范围：客户主从工作台、Hash 状态恢复和翻译标记已继续完善，最新结果见文末“Hash 与框架能力复审”。前半保留首次外观自审的证据范围。

2026-10-29，按 Interface-Design.md 的新验收表复审。本记录替代此前用浏览器通过数量概括“视觉通过”的结论。范围是后台三种布局及共享 Views，使用虚构、本机保存的数据；不代表整个组件库或 WCAG 合规认证。

## 结论与证据边界

本次支持组合的视觉与代表任务自审已执行，已确认的主要问题均修复并复验。语言策略已由用户确认：master 自动翻译并生成翻译文件，模板只维护 `{#...#}` 标记，不另建词典。后续 Hash/分栏复审见本文末的追加记录。

自审覆盖默认/ui-sm/ui-lg × 普通/ui-link × 明/暗，三个布局各在 1280/390px 检查列表外壳、工具、列对齐、滚动、底栏。其余十一种 View 在同一侧栏宿主各生成并审核上述 24 种呈现；业务 View 本身不按布局复制。另检查设置菜单、选中态、错误恢复和确认弹层的十二种组合，以及 320/767/768/991/992px 边界。使用对照图检查模式一致性，对手机导航、极窄布局、表单、选中行、弹层等关键区域查看原图/原生浏览器。

自动采证与测量、人工视觉判断、实际任务分别记录。测量覆盖当前可见、适用的普通文本及输入边界，排除禁用控件与装饰分隔符；不是全站可访问性扫描。十一种 View 的 264 个呈现记录中，测量范围内无未处理的文本对比失败，输入边界最小记录为 3.43:1。客户选中背景上的名称另有 4.5:1 回归断言。未测量的组合、图片/伪元素、全部焦点指示及所有屏幕阅读器行为不能据此声称达标。

200% 根字号与 320 CSS px 重排已检查。应用内浏览器原生 Cmd+Plus 没有改变 innerWidth/devicePixelRatio，本次不声称已验证原生浏览器 200% 缩放。专家自审不等于真实用户测试，未编造用户用时、完成率或满意度。

## 各类页面的视觉判断

以下每行均比较默认/sm/lg、普通/link、明/暗的桌面/手机呈现。外壳最终分组另用三布局矩阵复验。表中的通过是本次专家自审结论；语言一致性作为全局次要待决项单列。

| View/区域 | 布局/间距 | 颜色/重点 | 选择与操作判断 |
| --- | --- | --- | --- |
| 概览 | 两列手机指标、内容自然滚动；桌面概览列与记录/快捷区明确 | 数字优先、说明退后；避免每个指标使用独立强色 | 待跟进/进行中可直接进入对应筛选；新建入口在记录之前 |
| 客户列表 | 表头/行对齐，筛选分组，工具/底栏固定 | 选中面与名称可读；状态徽标同时有文字 | 查询一个提交入口、排序独立、批量跟进集中于选择上下文 |
| 客户详情 | 联系信息与关联订单分区，窄屏按流重排 | 编辑优先，关注次要，ID弱化 | 明确返回；编辑、关注和进入关联订单不需猜测 |
| 客户编辑 | 桌面两列、手机单列；动作在完整表单后，可滚动到达 | 标签/输入/错误关系清晰，保存与取消区分 | 一份草稿；保存前可取消；开发接入说明移出业务表单提示 |
| 订单列表/详情 | 金额右对齐、单位明确；详情动作自然换行 | 当前状态有文字，推进与取消语义不同 | 客户可达；取消有确认，完成后不提供非法推进 |
| 个人资料/偏好 | 标签及控件对齐，分组与说明有留白 | 未改动保存禁用；恢复/撤销为次要 | 偏好有保存边界，避免一改设置就意外换布局/外观 |
| 操作记录 | 搜索靠近结果、记录用稳定分隔，长内容可换行 | 标题/详情/时间逐级弱化 | 直接搜索，空结果可恢复；不添加无必要过滤配置 |
| 状态与恢复 | 读取、保存失败、重置按职责分区 | 错误持续可见，危险动作在独立区域 | 重试保留内容、草稿不丢、重置有具体后果与取消 |
| 指南/缺失路由 | 文字与源码入口清楚；错误不成为死路 | 导航与内容区分，恢复按钮突出 | 指南集中开发信息；缺失路由可回概览 |
| 设置/选择/弹层 | 菜单不裁断；底栏单行；确认按钮可聚焦 | 禁用、选中、焦点与主题表现分开检查 | Enter开设置、Escape返回焦点、重试与确认取消均真实执行 |

## 操作便捷与选择负担

实际完成：概览→浏览客户→记录→编辑→保存→返回列表。除字段输入外，主要入口各一步；保存后可直接返回，不必重新展开导航。原生浏览器还用“备注输入→Tab→Enter”保存，重载后从详情返回列表。相关自动场景覆盖搜索/条件、分页、批量动作、订单推进/取消、草稿放弃与保存失败。

没有通过删除功能伪装成“选择更少”：搜索、排序、视图/设置、业务动作按职责分组；手机把大量页面入口收进有当前名称的菜单，把混合分区保留为原生选择。未知图标不承担主操作；设置/主题等熟悉辅助图标保留可访问名称。正文/行与其他目标保留间距；小于24px的行内链接、原生控件与孤立文字按钮按适用的行内/标签/间距例外检查，而未声称所有元素均为24px方块。

## Hash 与框架能力复审

用户确认翻译由 master 自动处理，仅需 `{#...#}`；演示脏数据无需清理。本次没有新增词典或翻译服务，没有清理用户/演示数据，没有修改 State。

新增 `views/customers/workspace.html`：三种外壳共同挂载同一工作台，内部用 SplitPane + 两个 Pane，并通过 View 引用原来的 list.html/detail.html。Resizer 由 SplitPane 自动提供，支持鼠标/触控及键盘；宿主不另写分栏、宽度控制或第二个 Resizer。默认宽度 520，个人偏好绑定 LocalStorage；资源、呈现、窄屏面板绑定 Hash。
